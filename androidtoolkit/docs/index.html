核心特性

把 ADB 的能力，装进一个界面里

从设备管理到远程操控，从团队协作到 AI 调试，一个工具覆盖完整链路。

图形化管理

自动发现并列出所有 ADB 设备，点击即可选中连接。再也不用记忆 adb -s、adb devices 等命令，也无需手动复制设备序列号。

远程控制

内置低延迟投屏，直接查看设备实时画面，并支持点击、滑动、按键等操作。远程调试如同操作本地设备一样顺手。

代理共享

单台设备即可被多人同时访问，通过代理服务统一转发指令与画面，方便团队协作开发与联调测试。

MCP 支持

内置 MCP 服务，可将调试能力暴露给外部 AI Agent。让智能助手直接连接并调试远程真机，实现自动化测试与排障。

工作流程

三步，开始调试

01

连接设备

USB 或 Wi-Fi 连接设备，工具自动识别并在列表中展示，选择目标设备即可。

02

查看与控制

打开远程画面窗口，实时查看并操控设备，同时执行安装、日志等常规调试操作。

03

共享或托管

开启代理让团队成员接入，或启动 MCP 交由 Agent 自动完成调试任务。

代理 · 协作

一台设备，整个团队一起用

AndroidToolkit 内置代理服务，可把本机连接的设备共享到网络中。 团队成员无需各自插线，即可同时查看画面、下发指令，特别适合 远程办公、真机联调与多人测试的场景。

  • 单设备多会话并发访问
  • 统一的连接与指令转发
  • 跨局域网协作调试真机

MCP · AI Agent

让 Agent 直接调试远程设备

通过内置的 MCP（Model Context Protocol）服务，你可以把 ADB 调试能力开放给支持 MCP 的 AI Agent。Agent 能够自主连接 远程设备、执行命令、抓取日志，把重复性的调试工作交给自动化。

  • 标准 MCP 协议，兼容主流 Agent 客户端
  • 远程设备连接与指令执行
  • 面向上层自动化调试与排障
